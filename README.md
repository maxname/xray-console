# Xray Console

Веб-панель для одного администратора: ставит и обслуживает Xray-core
(VLESS + REALITY + XHTTP) на удалённых серверах по SSH.

Панель работает на своём сервере, Xray — на управляемых. Чтобы добавить
сервер, достаточно адреса, порта, логина и пароля: панель сама ставит свой
SSH-ключ, загружает Xray, пишет конфигурацию и проверяет, что через неё
проходит соединение.

## Что умеет

- **Установка** в восемь шагов с журналом; при сбое — повтор с того же шага
  или полный откат. Серверу не нужны ни curl, ни доступ к GitHub: релиз Xray
  панель скачивает сама и сверяет с опубликованной SHA-256.
- **Настройки и шаблоны.** Правка ничего не трогает на сервере; применение
  проверяет файл через `xray -test`, подменяет его, перезапускает Xray и
  проверяет соединение. Если что-то не так, прежний файл возвращается сам.
- **Проверки доступности** раз в минуту настоящим запросом через
  VLESS + REALITY + XHTTP, история и обзор.
- **Цепочки** серверов с балансировкой и резервом — средствами самого Xray.
- **Маршрутизация и подписки:** наборы правил на входном сервере и ссылки
  `/s/<токен>` для клиентов.
- **Обновление и удаление** Xray, по одному серверу или всем сразу.
- **Статистика и оповещения:** трафик, задержки, простои; Telegram и вебхук.
- **Устройства:** клиент Xray на Linux-машинах администратора и встроенный
  клиент на компьютере самой панели.

## Состояние

Проект молодой. Установщик проверяется на узлах в Docker
(`make integration`), но ещё не проверены:

- работа на настоящих VPS под нагрузкой;
- ссылка `vless://` и формат подписки в клиентских приложениях;
- доставка оповещений в настоящий Telegram.

Интерфейс только на русском.

## Требования

- **Сервер панели:** Linux, amd64 или arm64. Панель — один исполняемый файл с
  встроенным интерфейсом и базой SQLite.
- **Управляемые серверы:** Debian 11+ или Ubuntu 22.04+ с systemd, доступ по
  SSH под root или пользователем с sudo без пароля.
- **Сборка:** Go 1.27 (нужный тулчейн `go` скачает сам), Node.js и pnpm.
  Для интеграционных тестов — Docker.

## Сборка и запуск

```bash
make build
```

```bash
./bin/xray-console serve --listen 127.0.0.1:8080 --data ./data
```

При первом запуске панель печатает одноразовую ссылку для создания
администратора. Забытый пароль сбрасывается только с сервера панели:

```bash
./bin/xray-console reset-password --data ./data
```

Сборка под Linux для выкладки — `make release` (файлы в `bin/`).

### Основные флаги `serve`

| Флаг | Переменная окружения | По умолчанию | Назначение |
|---|---|---|---|
| `--listen` | `XRAY_CONSOLE_LISTEN` | `127.0.0.1:8080` | адрес, на котором слушает панель |
| `--data` | `XRAY_CONSOLE_DATA` | `./data` | каталог с базой и главным ключом |
| `--trusted-proxies` | `XRAY_CONSOLE_TRUSTED_PROXIES` | эта машина, если `--listen` на `127.0.0.1` | адреса прокси, чьим заголовкам о клиенте верить |
| `--check-url` | `XRAY_CONSOLE_CHECK_URL` | `https://www.gstatic.com/generate_204` | что запрашивать при проверке соединения |
| `--check-interval` | — | 1 минута | как часто проверять доступность |
| `--traffic-interval` | — | 5 минут | как часто снимать счётчики трафика |
| `--timezone` | `XRAY_CONSOLE_TZ` | пояс системы | часовой пояс панели, например `Europe/Moscow`: по нему идут тихие часы оповещений и сутки на графиках |

## Только за обратным прокси

Панель сама говорит по обычному HTTP и TLS не умеет — так задумано. Ставьте
перед ней обратный прокси с TLS (nginx, Caddy, Angie) и оставляйте `--listen`
на `127.0.0.1`. Без TLS пароль администратора и root-пароли добавляемых
серверов пойдут по сети открытым текстом.

Прокси должен передавать панели два заголовка: `X-Forwarded-For` (адрес
посетителя) и `X-Forwarded-Proto` (`https`). По первому панель считает
неудачные попытки входа, по второму понимает, что cookie сессии можно
пометить `Secure`. Для nginx:

```nginx
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
```

Пока панель слушает только на `127.0.0.1`, прокси на той же машине она
доверяет сама. Если прокси стоит на другой машине, назовите его адрес в
`--trusted-proxies` и закройте порт панели для всех остальных. Панель,
запущенная на внешнем адресе без прокси, предупреждает об этом при старте.

## Данные и резервные копии

Всё состояние лежит в каталоге `--data`: база `xray-console.db` и главный
ключ `master.key`, которым зашифрованы SSH-ключ панели, ключи REALITY и
токены. Копируйте оба файла; без ключа база бесполезна, а вместе они дают
доступ ко всем серверам — храните копии соответственно.

## Разработка

```bash
make test
```

`make test` — `go vet`, тесты Go, ESLint и Vitest.

```bash
make integration
```

`make integration` поднимает узел Debian в Docker и прогоняет на нём
настоящий установщик: установка, сбой и откат, применение настроек,
устройство, обновление, удаление. `make integration-chain` — то же для
цепочки из трёх узлов.

Только интерфейс: `cd web && pnpm dev` (запросы к `/api` уходят на
`127.0.0.1:8080`).

Как устроен код и какие решения приняты — в [CLAUDE.md](CLAUDE.md).
